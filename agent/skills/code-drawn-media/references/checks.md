# Checks before "done"

## All three kinds

- Attachments used for style and facts only. No pasted stock. No CDN meshes.
- Budget named (time, tokens, or "stop after one level / 30 seconds").
- Effort started at **high**. Max only after a visible gap on a small test.
- Strongest coding model wrote the brief. Long repetitive write/render may
  use a cheaper sibling (**model-router**).
- Output opens locally without a login.

## Game

- Win **and** lose are implemented, not only described.
- One HTML file. `three.js` may be inlined or vendored in that file.
- Walk and attack: stills inspected, then the cycle.
- Screenshots: start, mid, end. One full playthrough after the last fix.

## Video

- Shot list approved before the full render.
- One still per shot inspected.
- Contact sheet of the finished clip inspected.
- Audio exists (code-generated). One-frame impact delay is optional.
- 1080p 60 fps unless the user named another size.

## Walkthrough

- Measurement list confirmed before walls go in.
- Three eye-height room shots compared to the photos.
- Doors and windows match the plan, not a symmetric guess.

## Stop

List the next three upgrades. Do not implement them in the same turn.
