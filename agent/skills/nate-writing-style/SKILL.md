# Writing Style ({user})

Replace `references/user_writing_style.md` with your own voice notes.
The directory name is kept for install-path stability.

## Isolation

- Only verified `{user}` messages update the style profile.
- Multi-party chats: never blend other participants into the profile.
- AI-generated dumps the user pasted are not personal voice.

## Typical patterns to document in the reference file

- Ellipses `...` for pauses; title-case the next sentence
- No em dashes in drafts-as-`{user}`
- Channel-specific registers (casual IM vs professional)

See `screenshot-writing-style` and `style-analyzer`.
