# Verify

A thumbnail of page 1 is not verification.

1. `pdftoppm -png -r 140` **every** page.
2. Read each PNG.
3. Confirm: no overlap, no clipped type, no figure under a heading, no
   color key covering body, no unreadably small labels.
4. Confirm the plot device (or the first jargon word) is taught before a
   diagram uses it.
5. Confirm the shape matches the request (process vs comparison vs incident
   vs field-story).
6. Confirm the cover kicker and footer name the topic, not a product,
   employer, or repo.

Fix and re-raster until every page is clean. Then stop.
